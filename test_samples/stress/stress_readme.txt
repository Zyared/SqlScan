Набор стресс-проверок для SqlScan (загрузите через «Загрузить из файла»).

stress_empty.txt              — пустой файл.
stress_bom_only.txt           — только UTF-8 BOM (пустое содержимое после BOM).
stress_bad_utf8.txt           — неверные UTF-8 последовательности (программа не должна падать).
stress_nulls_and_ctrl.txt     — нули и управляющие байты (нули при чтении заменяются на пробел).
stress_1mb_A.txt              — 1 МБ символа «A» (проверка времени и лимита анализа 5 МБ).
generate_large_files.py       — запустить: python generate_large_files.py (создаёт stress_ten_mb_minus_one.txt у границы 10 МБ).
stress_long_mixed.txt         — длинная строка с повторяющимся « OR 1=1» (тяжёлый отчёт).

Ожидание: без падений. Анализируется не более ~512 КБ входа; в поле отчёта нормализованная строка показывается не более ~64 КБ (см. текст отчёта).
Файлы > 10 МБ при открытии отклоняются.
