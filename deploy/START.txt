SqlScan 2.0 для Windows x64

1. Установите MSI и откройте SqlScan из меню «Пуск» или распакуйте ZIP в обычную папку.
2. Для работы запустите SqlScan-Local.cmd. Появится «PostgreSQL подключена».
3. Для примера откройте examples\demo.log и нажмите «Проверить».
4. Для независимой проверки комплекта запустите Recheck.cmd. Входные данные пользователя сохраняются в отдельном от испытаний журнале.

Команды из корня распакованного комплекта
  Check-Scores.cmd                     Свежие примеры, ручной расчёт и сравнение с EXE
  Recheck.cmd                          Проверить хеши, базу, движок, GUI, восстановление и нагрузку
  Recheck.cmd -Quality                 Те же тесты и сравнение четырёх движков на пяти источниках
  Recheck.cmd -Quality -Cache D:\SqlScan-test-data
                                       Повторное использование проверенных исходных данных
  SqlScan-Local.cmd -Stop              Остановить личный сервер после закрытия приложения

Для первого измерения качества нужен интернет. После заполнения указанного кэша повторный прогон возможен автономно. В комплекте есть собственный тестовый Python, PostgreSQL и драйвер. Тесты GUI требуют обычного интерактивного сеанса. Результаты записываются в %LOCALAPPDATA%\SqlScan2\Checks. Путь печатается в конце. Успешный прогон завершается строкой PASS и кодом 0.
