# SqlScan 2.0 для Windows x64

## Первый запуск

Распакуйте комплект в обычную папку. Запустите **SqlScan-Local.cmd**. При первом запуске создаются пользовательская база и настройки. О готовности сообщает строка **PostgreSQL подключена · Активных правил: 18** внизу окна. Следующие запуски открывают тот же журнал. Для автономной проверки текста можно открыть **SqlScan.exe** напрямую.

В комплекте находятся сервер PostgreSQL и установочный пакет драйвера psqlODBC x64. Скрипт использует уже зарегистрированный драйвер либо распаковывает его в каталог пользователя и создаёт пользовательский DSN. Локальный сервер принимает подключения с этого ПК на адресе `127.0.0.1`. Программа работает от отдельной роли с доступом к схеме `sqlscan`. Настройки и каталог базы находятся в `%LOCALAPPDATA%\SqlScan2\Local`. Windows защищает пароли с помощью DPAPI текущего пользователя.

Если путь к распакованной папке содержит кириллицу, при первом создании базы скрипт временно назначает свободную букву диска каталогу служебных файлов PostgreSQL. Привязка снимается сразу после инициализации.

## Проверка текста и файлов

1. На вкладке **Проверка** введите текст или откройте файл `examples\demo.log` из комплекта. Нажмите **Проверить**.
2. У демонстрационного файла три строки. Вторая набирает 5 баллов по пяти разделителям и достигает порога. Вердикт файла становится подозрительным, когда хотя бы одна его строка достигает порога или содержит сигнатуру высокого риска. Баллы разных строк отображаются в общей сумме.
3. Отчёт показывает номера строк с единицы и позиции в байтах UTF-8 с нуля в нормализованной строке. Здесь же отображаются категория, вес и контекст каждого совпадения. Высокий риск подсвечивается в нормализованном тексте.
4. Нажмите **Экспорт отчёта…** и выберите TXT, CSV или HTML. Отчёт проверки содержит построчные оценки. В CSV сводка, строки и совпадения идут отдельными таблицами. HTML экранирует текст. CSV защищает текстовые поля от интерпретации как формул.

Программа открывает UTF-8 с BOM и без него и использует системную ANSI-кодировку Windows при ошибке UTF-8. Нулевые байты заменяются пробелами. По умолчанию предел открытия файла — 2 МиБ, предел анализа одной проверки — 512 КиБ. Поле ввода показывает до 256 Ки символов. При проверке только что открытого файла анализируется загруженный файл с учётом лимита движка. Если файл полностью помещается в поле, редактирование начинает новую проверку ручного ввода. Журнал и экспорт содержат каждое совпадение в проанализированной части. Для плотного текста движок повторно перечисляет позиции по сохранённому снимку правил. Окно сокращает длинные отчёты для быстрого просмотра.

Уровень «Низкий» соответствует нулевому баллу. «Средний» означает наличие совпадений без подозрительной строки. У подозрительной проверки уровень «Высокий», а при достижении двойного порога хотя бы в одной подозрительной строке — «Критический». Процентное кодирование ASCII раскрывается до двух раз, поддерживаются числовые HTML-сущности ASCII, именованные сущности кавычек и соединение частей слова, разделённых пустым блочным комментарием. Вердикт служит для первичной сортировки журналов. Измеренная полнота указана в протоколе испытаний.

Если файл целиком не помещается в поле ввода, SqlScan покажет начало в режиме «только для чтения». Кнопка **Проверить** анализирует исходный файл в пределах лимита анализа. При достижении лимита в отчёте указано, сколько байтов обработано. Кнопка **Ручной ввод** открывает пустое поле для другой проверки. В цветном отчёте число баллов меняет цвет от зелёного при 0 через тёмно-жёлтый при 50 к красному при 100 и выше. Порог подозрительности применяется к каждой строке отдельно.

## Журнал, сигнатуры и статистика

- **Журнал.** Страница содержит до 50 проверок. Нажмите заголовок столбца для сортировки. В фильтрах доступны период, вердикт, тип источника, часть имени файла и минимальный балл. Двойной щелчок открывает сохранённую проверку и экспорт её сводки и совпадений. **Экспорт выборки…** выгружает все строки, подходящие под фильтры, в выбранной сортировке. Удаление требует подтверждения.
- **Сигнатуры.** Добавляйте и редактируйте шаблоны длиной 1–64 символа, выбирайте категорию, вес 1–5 и флаг высокого риска. Правила перечитываются перед проверкой. Использованную в журнале сигнатуру можно отключить. История сохраняет прежние шаблон, вес и признак риска.
- **Статистика.** Вкладка показывает десять самых частых шаблонов, количество и долю подозрительных проверок и диаграмму по последним 30 датам, в которые выполнялись проверки.
- **Повторный файл.** Программа сверяет SHA-256 исходных байтов и предлагает открыть предыдущую запись. При отказе выполняется новая проверка.

База хранит размер, хеш, вердикт и фрагменты совпадений. Полный текст доступен в текущем окне и в его экспорте. В архивном отчёте представлены построчные баллы и вердикты, включая строки без совпадений. Окно показывает первые 150 строк и первые 150 совпадений, а экспорт включает все сохранённые данные. Если по ранней архивной записи невозможно восстановить построчные оценки, окно и экспорт укажут это. Если сервер отключится, можно продолжать анализ со встроенными правилами и экспортировать отчёт из окна. Следующая проверка или переход на вкладку с данными повторит попытку соединения. Автономные проверки не отправляются в журнал задним числом.

## Другая база и остановка локальной

Откройте **Приложение → Настройки базы данных…** и введите DSN либо строку ODBC. Кнопка проверки устанавливает соединение, проверяет или инициализирует схему и читает действующие сигнатуры. **Подключить** сохраняет строку в HKCU в зашифрованном виде. При прямом запуске EXE используется это подключение. Локальный командный файл выбирает свой экземпляр. **Приложение → Автономный режим** сбрасывает настройку подключения.

Закрытие окна оставляет локальную базу доступной другим окнам. Чтобы остановить её, закройте окна и запустите команду из папки комплекта.

```bat
SqlScan-Local.cmd -Stop
```

## Пакетная обработка

Входной CSV в UTF-8 содержит поле `text` и необязательное поле `label`. Одна запись соответствует одному образцу. Кавычки, запятые и переводы строк внутри полей поддерживаются. Для воспроизводимых измерений используется встроенный набор правил. Результат включает метку, предсказание (0/1), балл, риск, число совпадений и признак усечения. Входной лимит CSV — 64 МиБ. В PowerShell оператор вызова с конвейером позволяет дождаться GUI-процесса и затем проверить код выхода.

```powershell
& .\SqlScan.exe --batch .\examples\dataset.csv --out .\result.csv | Out-Null
$LASTEXITCODE
```

Код 0 означает успех, код 2 — ошибку аргументов или файла. Результат записывается только после успешной обработки всего набора. Для воспроизведения движка 1.0 добавьте `--legacy`.
