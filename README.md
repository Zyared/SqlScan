# SqlScan

Десктопное Windows-приложение для обнаружения SQL-инъекций в тексте. Анализирует строку или файл по набору паттернов, выставляет вес опасности и формирует цветной отчёт.

## Возможности

- Ввод текста вручную или загрузка из файла (до 2 МБ)
- 18 паттернов SQL-инъекций с весами от 1 до 5
- Цветовой градиент результата: зелёный → жёлтый → красный
- Подсветка опасных фрагментов в нормализованной строке
- Сохранение отчёта в файл UTF-8
- Динамическое изменение размера окна

## Как работает детектор

1. Входная строка **нормализуется**: приводится к нижнему регистру, несколько пробелов схлопываются в один
2. По нормализованной строке ищутся все **паттерны** из таблицы правил
3. За каждое вхождение к сумме прибавляется **вес** паттерна
4. Если найден хотя бы один паттерн с пометкой «высокий риск» или сумма весов ≥ 5 — строка считается **подозрительной**

### Таблица паттернов

| Паттерн | Вес | Высокий риск |
|---------|-----|--------------|
| `' or` | 3 | да |
| `" or` | 3 | да |
| `or 1=1` | 4 | да |
| `1=1` | 2 | нет |
| `;` | 1 | нет |
| `--` | 3 | да |
| `/*` | 2 | нет |
| `*/` | 2 | нет |
| `;--` | 4 | да |
| `union select` | 5 | да |
| `sleep(` | 4 | да |
| `benchmark(` | 4 | да |
| `xp_cmdshell` | 5 | да |
| `information_schema` | 3 | нет |
| `drop table` | 5 | да |
| `insert into` | 3 | нет |
| `update set` | 3 | нет |
| `delete from` | 3 | нет |

## Требования

- Windows 10 / 11
- Visual Studio 2019 или 2022 (с компонентом «Разработка классических приложений на C++»)
- Windows SDK (устанавливается вместе с Visual Studio)

## Сборка

1. Открыть `SqlScan.slnx` в Visual Studio
2. Выбрать конфигурацию `Debug` или `Release`, платформу `x64`
3. `Build → Build Solution` (или `Ctrl+Shift+B`)
4. Готовый `.exe` находится в папке `x64\Debug\` или `x64\Release\`

## Структура проекта

```
SqlScan/
├── SqlInjectionDetector.h/.cpp  — движок обнаружения (паттерны, нормализация, поиск)
├── SqlScanDlg.h/.cpp            — главное окно (UI, файлы, отчёт)
├── SqlScan.h/.cpp               — точка входа MFC-приложения
├── pch.h/.cpp                   — предкомпилированный заголовок
├── framework.h                  — подключение MFC и Windows
├── resource.h / SqlScan.rc      — ресурсы диалога (ID контролов, шаблон)
├── test_samples/                — тестовые файлы и стресс-тесты
├── GUIDE.md                     — учебный разбор каждого слова в коде
└── README.md                    — этот файл
```
